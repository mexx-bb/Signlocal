# **App Name**: SignLocal

## Core Features:

- Open DOCX: Open and display .docx documents locally.
- Signature Field Placement: Manually place signature fields at specific locations within the document, or place them automatically on defined markes.
- Signature Capture: Capture signatures via image upload or drawing.
- PDF Export: Save the document as a PDF, embedding signatures into the PDF document.
- PDF Printing: Print the final PDF document directly from the application.
- Markup Extraction: The App will find the desired signature positions by identifying and parsing Markup in the original document, as specified via settings.
- Audit Log: Maintain a local audit log with timestamps and user actions related to document processing.

## Style Guidelines:

- Primary color: Deep indigo (#3F51B5) to inspire trust.
- Background color: Light gray (#F0F2F5) for a clean and professional feel.
- Accent color: Amber (#FFC107) to highlight interactive elements and calls to action.
- Headline font: 'Space Grotesk' (sans-serif) for headers. Body font: 'Inter' (sans-serif) for a modern and readable text.
- Use a consistent set of icons throughout the application for actions like opening files, adding signatures, saving, and printing. Prefer minimalist icons.
- Employ a clean, intuitive layout that guides the user through each step of the document signing process. Use a single-window design to reduce complexity.
- Incorporate subtle animations during signature placement and document processing to provide feedback to the user without being intrusive.
