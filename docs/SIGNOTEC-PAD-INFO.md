## Wichtige Informationen

### signotec LCD Signature Pad Gamma

Das **signotec LCD Signature Pad Gamma** ist ein professionelles Unterschriften-Pad mit:
- LCD-Display für Anzeige von Informationen
- Touch-Sensitivität für Unterschriften-Erfassung
- USB-Verbindung
- Unterstützung für die signoPAD-API Web

### STPadServer 3.5.0.0

Die **STPadServer Version 3.5.0.0** ist die neueste Version der Signotec-Server-Software, die:
- WebSocket-Verbindungen unterstützt (Port 49494)
- Die signoPAD-API Web bereitstellt
- Mit der STPadServerLib.js JavaScript-Bibliothek arbeitet

## Verwendung

1. **Pad anschließen:** Das Pad ist bereits angeschlossen und erkannt ✅
2. **Software starten:** STPadServer sollte laufen (prüfen Sie den Task-Manager)
3. **In SignLocal verwenden:** 
   - Öffnen Sie ein Dokument
   - Klicken Sie auf "Signieren"
   - Wählen Sie den Tab "Signotec Pad"
   - Klicken Sie auf "Signatur erfassen"

## Support

Bei Problemen:
- Prüfen Sie, ob STPadServer läuft (Task-Manager)
- Prüfen Sie die Browser-Konsole (F12) auf Fehlermeldungen
- Stellen Sie sicher, dass das Pad angeschlossen ist
- Kontaktieren Sie den Signotec Support: https://www.signotec.com
